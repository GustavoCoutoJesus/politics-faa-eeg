This is the replication package for the Frontal Alpha Asymmetry in Politics project. 
It contains 3 main folders:
- Data Description
  The exact participant folders present before and after preprocessing are listed. Some folders might contain missing data, which is why the list shortens.
- Quality Check Reports
  During the processing the data, quality checks were run to confirm the validity of the pipeline.
- Scripts
  The code used to preprocess, run analyses and quality checks is provided. Placeholder path locations must be replaced by user. 
  Channel configuration csvs and a python ENV list of packages are made available here. 

In order to run the code seamlessly, the user must first guarantee a similar bids folder structure.
See https://bids.neuroimaging.io/getting_started/folders_and_files/folders.html for further details.
